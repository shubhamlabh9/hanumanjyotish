# About the Project

Hanuman Jyotish is a traditional Indic divination system consisting of forty different chakras (prediction wheels). This project attempts to preserve and modernize that traditional system through a responsive web application.

Instead of keeping the knowledge limited to printed books, this project converts the traditional wheel into an interactive digital experience that anyone can use through a web browser.

The application allows users to select a chakra, spin the traditional wheel, and instantly receive predictions in a modern interface.

---

# Project Objective

The primary objectives of this project are:

- Preserve traditional Hanuman Jyotish digitally.
- Make the prediction process interactive.
- Improve accessibility through modern web technologies.
- Organize the traditional data into structured JSON format.
- Create an educational and research-oriented digital implementation.

# How It Works

1. Open the application.
2. Select a Hanuman Jyotish Chakra.
3. Spin the wheel.
4. The wheel stops automatically.
5. The selected symbol determines the corresponding speaker.
6. The prediction is displayed instantly.
